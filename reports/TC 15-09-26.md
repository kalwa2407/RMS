TC001
Table Order (QR Code) Submission

Steps:
1. Scan table QR code to open `TableOrder.jsx`
2. Add items to cart and submit order
3. Verify order appears on Captain/Admin dashboard

Expected:
Order should be placed with order_type "DINE_IN" and the specific table number, without requiring a delivery address.


TC002
Captain Session Creation

Steps:
1. Log in as Captain and select an empty table
2. Enter customer name and initiate a new session
3. Add initial items and tap "Send to Kitchen"

Expected:
A new `TableSession` should be created in the backend with status "active" and linked to the correct table number.
